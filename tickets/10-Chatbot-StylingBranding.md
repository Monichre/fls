# 10-Chatbot-StylingBranding.md

## Title
Implement Styling and Branding for Chatbot Modal and UI

## Description
Apply consistent styling and branding to the chatbot modal, trigger, and chat UI. Use shadcn/ui and Tailwind to match the site's design system. Ensure the modal header, avatar, buttons, and chat bubbles reflect FLS branding and are visually appealing on all devices.

## Acceptance Criteria
- Modal, trigger, and chat UI match site branding
- Use shadcn/ui and Tailwind for all styling
- Modal header includes avatar, name, and close button
- Chat bubbles are styled for user and AI messages
- Responsive and visually appealing on all devices
- Color contrast and font sizes meet accessibility standards

## Implementation Notes
- Reference existing site color palette and typography
- Use Tailwind for spacing, colors, and layout
- Style chat bubbles for both user and AI
- Test on light/dark backgrounds

## References
- [shadcn/ui](https://ui.shadcn.com/)
- [Tailwind CSS](https://tailwindcss.com/)

## Effort Estimation
- 1 story point
- High confidence
- Low complexity

## Testing Guidelines
- Manual: visual review, mobile/desktop
- Accessibility: color contrast, font size
