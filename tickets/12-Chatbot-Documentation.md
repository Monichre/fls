## Title
Document Chatbot Modal, UI, API, and Persona

## Description
Create comprehensive documentation for the chatbot feature, including architecture, component structure, API usage, persona configuration, and extension guidelines. Documentation should be in Markdown, follow project conventions, and be placed in the appropriate docs directory. Include diagrams or code samples as needed.

- Documentation covers modal, UI, API, persona config
- Explains architecture, data flow, and extension points
- Includes code samples and diagrams where helpful
- Follows project documentation conventions
- Placed in the correct docs directory (e.g., `docs/`)
- Easy for new developers to follow and extend

## Implementation Notes

- Reference related tickets and code
- Document persona update process
