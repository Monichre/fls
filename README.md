Add event tracking to sign ups. to catalogue click

## Environment Variables

This project uses environment variables for configuration. To get started:

1. Copy `.env.example` to `.env.local`
2. Update the values in `.env.local` with your actual API credentials

### Required Environment Variables

- `LANGBASE_AUTH_TOKEN`: Authentication token for the Langbase AI API
- `NEXT_PUBLIC_LANGBASE_API_ENDPOINT`: Endpoint URL for the Langbase AI API
